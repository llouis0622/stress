# MINAM BREAK

부산미남병원과 주변 땅을 부수고, 지구 반대편까지 뚫는 3D 미니게임입니다.

**[게임 실행하기](https://llouis0622.github.io/stress/)**

- 건물을 클릭하거나 터치해서 부숴 보세요.
- 18층 병실·간호실을 둘러보고, 벽과 바닥을 무너뜨릴 수 있습니다. 캐릭터는 안전하게 대피해요.
- ‘내부 단면’과 층 선택으로 내부를 볼 수 있습니다. 내부 배치는 게임용 창작입니다.
- 망치·충격파·레이저·운석·지진·드릴·폭탄·쇠공·블랙홀을 사용할 수 있습니다.
- ‘지면 부수기’에서 맨틀·외핵·내핵을 지나 반대편 지각까지 파 보세요. 깊이는 게임에 맞게 압축했습니다.
- `1~9`: 도구 · `E`: 굴착 따라가기 · `H`: 병원 · `U`: 되돌리기 · `R`: 전체 복구
